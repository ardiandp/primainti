# PRD Phase 8 --- Frontend Website Lengkap Sesuai Mockup

**Dependensi:** Phase 4--7 untuk data yang dibutuhkan.

## Halaman

1.  Beranda: hero, profil ringkas, produk unggulan, fasilitas,
    sertifikasi yang diverifikasi, CTA, kontak ringkas.
2.  Tentang Kami: sejarah sejak 2001 jika disahkan, visi/misi,
    kompetensi, mutu, keselamatan, lingkungan, sertifikasi.
3.  Katalog produk dan detail produk.
4.  Galeri.
5.  Fasilitas.
6.  Kontak.
7.  404 dan halaman legal bila diperlukan.

## UI/UX

-   Gaya Modern Industrial Corporate: navy, putih, oranye sesuai
    mockup/brand guide.
-   Header/footer shared components.
-   Responsive mobile/tablet/desktop.
-   Breadcrumbs, cards, buttons, forms, spec table konsisten.
-   Loading/empty/error/success states.
-   Accessibility dasar: semantic headings, labels, alt text, keyboard
    focus, contrast.
-   Gunakan data CMS, bukan hardcode untuk konten bisnis.

## Aturan konten

-   Mockup adalah referensi desain, bukan sumber kebenaran.
-   Angka statistik, foto, sertifikat, spesifikasi dan klaim harus
    disetujui.
-   Gunakan placeholder yang jelas hanya di development.

## Acceptance criteria

-   Semua halaman utama tampil sesuai mockup yang disetujui.
-   Semua halaman utama responsif.
-   Navigasi, CTA, filter, galeri, dan detail produk berfungsi.
-   Data halaman berasal dari CMS/settings/media.
-   Tidak ada placeholder/demo di production.
