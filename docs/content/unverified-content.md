Fase: PRD Phase 0

## 5. Aturan kerja

1. Item berstatus `Belum diterima` **tidak** boleh ditulis ke database, halaman, atau seed sebagai konten final.
2. Pengisian wajib mencantumkan tanggal persetujuan dan nama penyetujui di kolom Status/Catatan.
3. Dilarang mengarang, menghalluskan, atau menebak isi konten (larangan Master Roadmap).
4. Setiap perubahan status = pembaruan dokumen ini + commit.
